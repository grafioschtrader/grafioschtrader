[historical] Eine für Grafioschtrader betriebene Frankfurter-Instanz. Sie liefert genau dieselben Daten und dieselbe Schnittstelle wie die öffentliche Instanz, deshalb gilt hier alles, was zum Konnektor Frankfurter beschrieben ist.
Hier ist keine Eingabe erforderlich. Weder ein API-Schlüssel noch eine URL-Erweiterung wird benötigt: Beide Währungen werden direkt dem Währungspaar entnommen.
Dieser Konnektor erscheint nur dann in der Auswahl, wenn ein Administrator die Adresse der Instanz in gt.datafeed.gtfrankfurter.url hinterlegt hat. Er besteht, damit die Last auf zwei Instanzen verteilt werden kann oder damit eine Installation von der öffentlichen Instanz unabhängig bleibt.
