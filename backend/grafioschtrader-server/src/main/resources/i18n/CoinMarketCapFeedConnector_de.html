[historical] Öffnen Sie die gewünschte Kryptowährung auf CoinMarketCap. Suchen Sie in den Netzwerkanfragen der Browser-Entwicklerwerkzeuge nach /chart und öffnen Sie den Aufruf von cryptocurrency/detail/chart.
Entnehmen Sie der Request-URL die numerischen Werte der Parameter id und convertId. Geben Sie diese zusammen mit den Währungssymbolen im Format KRYPTO_SYMBOL=id,KURSWAERUNG_SYMBOL=convertId ein. Übernehmen Sie interval, range, timeStart und timeEnd nicht; Grafioschtrader erzeugt diese Parameter selbst.
Geben Sie zum Beispiel aus ...?id=1027&interval=7d&convertId=2781&range=All für ETH/USD den Wert ETH=1027,USD=2781 ein. Die Zahlen sind CoinMarketCap-Asset-IDs: Bitcoin hat dort die ID 1; deshalb wird BTC/CHF als BTC=1,CHF=2785 eingegeben.
Im Chart-Aufruf muss die Kryptowährung immer an erster Stelle stehen. Verwenden Sie daher BTC=1,CHF=2785 sowohl für BTC/CHF als auch für CHF/BTC; für CHF/BTC berechnet Grafioschtrader automatisch den Kehrwert des Kurses.
Historische Tageswerte werden in Drei-Jahres-Fenstern geladen. CoinMarketCap liefert über diesen Chart-Endpunkt keine täglichen Eröffnungs-, Höchst- und Tiefstkurse.
Es ist kein API-Schlüssel erforderlich. Dies ist ein undokumentierter Webseiten-Endpunkt, den CoinMarketCap jederzeit unangekündigt ändern oder einschränken kann. [intra] Verwenden Sie denselben Wert im Format KRYPTO_SYMBOL=id,KURSWAERUNG_SYMBOL=convertId wie für die historischen Daten. Letzter Kurs, Zeitstempel, Tageseröffnung, Tageshoch, Tagestief, Vortagesschluss und prozentuale Änderung werden aus Fünf-Minuten-Chartpunkten abgeleitet.
Es ist kein API-Schlüssel erforderlich. Dies ist ein undokumentierter Webseiten-Endpunkt, den CoinMarketCap jederzeit unangekündigt ändern oder einschränken kann.
