DivvyDiary supplies dividend and split histories for equities and exchange traded funds.
No URL extension is required: the instrument is identified by its ISIN, which must be entered on the instrument.
Dividend requests always run without an API key, even when a key is configured for splits. Both the ex-date and the pay date are supplied.
Split history requires an API key. An administrator must enter the instance's DivvyDiary key under Connector API Keys; DivvyDiary then becomes available as a split source. Only split requests send this key.
This source does not supply prices. Existing instruments are not switched automatically.
