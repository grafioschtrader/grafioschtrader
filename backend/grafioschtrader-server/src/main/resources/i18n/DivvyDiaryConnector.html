DivvyDiary supplies the dividend history of equities and exchange traded funds.
No entry is required here. Neither an API key nor a URL extension is needed: the instrument is identified by its ISIN, which must therefore be entered on the instrument.
This data source can only be chosen for dividends, it delivers neither prices nor splits. A share split has no effect on the dividend payments delivered here.
Both the ex-date and the pay date are supplied.
