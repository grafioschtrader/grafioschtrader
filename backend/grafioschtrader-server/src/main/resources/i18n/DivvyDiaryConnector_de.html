DivvyDiary liefert die Dividendenhistorie von Aktien und börsengehandelten Fonds.
Hier ist keine Eingabe erforderlich. Weder ein API-Schlüssel noch eine URL-Erweiterung wird benötigt: Das Instrument wird über seine ISIN angesprochen, diese muss deshalb auf dem Instrument erfasst sein.
Diese Datenquelle kann nur für Dividenden gewählt werden, sie liefert weder Kurse noch Splits. Ein Aktiensplit hat keine Auswirkung auf die hier gelieferten Dividendenzahlungen.
Es werden sowohl das Ex-Datum als auch das Zahlungsdatum geliefert.
