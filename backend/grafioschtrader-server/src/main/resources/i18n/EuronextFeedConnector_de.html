Euronext ist der Handelsplatz von Amsterdam, Brüssel, Dublin, Lissabon, Oslo und Paris. Nur ein Instrument, das an einem davon gehandelt wird, kann diese Datenquelle nutzen.
Hier ist keine Eingabe erforderlich. Weder ein API-Schlüssel noch eine URL-Erweiterung wird benötigt: Grafioschtrader bildet die Anfrage aus der ISIN und dem Handelsplatz des Instrumentes.
[historical] Die Tagesendkurse werden den Chartdaten entnommen. Diese führen keine Angaben zu Eröffnung, Höchst- und Tiefstkurs des Tages, doch Grafioschtrader verwendet diese Werte zurzeit nicht.
Ein Tagesendkurs wird nur für einen Tag geliefert, an dem das Instrument auch tatsächlich gehandelt wurde.
