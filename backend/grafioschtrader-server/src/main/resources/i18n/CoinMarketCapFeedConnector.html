[historical] Open the desired cryptocurrency on CoinMarketCap. In the browser developer tools, search the network requests for /chart and open the request to cryptocurrency/detail/chart.
From the request URL, extract the numeric values of id and convertId. Enter them together with their currency symbols in the form CRYPTO_SYMBOL=id,QUOTE_SYMBOL=convertId. Do not copy interval, range, timeStart or timeEnd; Grafioschtrader generates these parameters.
For example, from ...?id=1027&interval=7d&convertId=2781&range=All, enter ETH=1027,USD=2781 for ETH/USD. The numbers are CoinMarketCap asset IDs: Bitcoin's ID happens to be 1, so BTC/CHF is entered as BTC=1,CHF=2785.
The chart request must always have the cryptocurrency first. Therefore, use BTC=1,CHF=2785 for both BTC/CHF and CHF/BTC; for CHF/BTC, Grafioschtrader calculates the reciprocal price automatically.
Historical daily snapshots are loaded in three-year windows. CoinMarketCap does not provide daily open, high and low values through this chart endpoint.
No API key is required. This is an undocumented website endpoint and may be changed or restricted by CoinMarketCap without notice. [intra] Use the same CRYPTO_SYMBOL=id,QUOTE_SYMBOL=convertId value as for historical data. The last price, timestamp, daily open, high, low, previous close and percentage change are derived from five-minute chart points.
No API key is required. This is an undocumented website endpoint and may be changed or restricted by CoinMarketCap without notice.
