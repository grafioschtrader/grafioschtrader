CryptoCompare is the standard data source for intraday and historical prices of cryptocurrencies.
No entry is required here. A URL extension is not needed: both currencies are taken directly from the currency pair, and Grafioschtrader builds the request itself.
This data source requires an API key, which the administrator enters once for the whole instance. The request limits of the free key are comparatively high.
A currency pair is only accepted when the provider offers it. The answer arrives with an HTTP status of success even for an unknown pair, therefore Grafioschtrader evaluates the text of the answer instead.
[historical] One request delivers a limited number of days, so a long price history is loaded with several consecutive requests.
