Euronext is the trading venue of Amsterdam, Brussels, Dublin, Lisbon, Oslo and Paris. Only an instrument traded at one of them can use this data source.
No entry is required here. Neither an API key nor a URL extension is needed: Grafioschtrader builds the request from the ISIN and the stock exchange of the instrument.
[historical] The end-of-day prices are taken from the chart data. It carries no open, high and low price of the day, but Grafioschtrader currently does not use those values.
An end-of-day price is only supplied for a day on which the instrument was actually traded.
