CryptoCompare ist die Standard-Datenquelle für Innertag- und historische Kurse von Kryptowährungen.
Hier ist keine Eingabe erforderlich. Eine URL-Erweiterung wird nicht benötigt: Beide Währungen werden direkt dem Währungspaar entnommen, und Grafioschtrader bildet die Anfrage selbst.
Diese Datenquelle benötigt einen API-Schlüssel, den der Administrator einmalig für die ganze Instanz erfasst. Die Anfragelimits des kostenlosen Schlüssels sind vergleichsweise hoch.
Ein Währungspaar wird nur akzeptiert, wenn der Anbieter es führt. Die Antwort trifft auch bei einem unbekannten Paar mit einem erfolgreichen HTTP-Status ein, deshalb wertet Grafioschtrader stattdessen den Text der Antwort aus.
[historical] Eine Anfrage liefert eine begrenzte Anzahl Tage, eine lange Kurshistorie wird deshalb mit mehreren aufeinanderfolgenden Anfragen geladen.
