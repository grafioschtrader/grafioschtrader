[historical] A Frankfurter instance hosted for Grafioschtrader. It serves exactly the same data and the same API as the public instance, so everything written about the Frankfurter connector applies here as well.
No entry is required here. Neither an API key nor a URL extension is needed: both currencies are taken directly from the currency pair.
This connector only appears in the selection when an administrator has configured the address of the instance in gt.datafeed.gtfrankfurter.url. It exists so that the load can be spread across two instances, or so that an installation can stay independent of the public one.
